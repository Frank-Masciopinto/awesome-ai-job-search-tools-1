# Tool Submission Template

Open an issue or PR and copy this format.

```md
**Tool name:** [Name]
**Website:** [URL]
**Category:** [ATS / Resume builder / Resume tailoring / Job matching / Job tracker / Email finder / Chrome extension / Auto-apply / Interview / Salary / Scam checker]
**Pricing:** [Free / Freemium / Paid / Open source]
**What it does:** [One sentence — what specifically does it do?]
**Who it helps:** [Students / new grads / experienced / role type]
**Why include it:** [What makes it stand out? Don't say "best in the world." Be specific.]
**Conflict of interest disclosure:** [Are you affiliated with the tool? Required.]
```

## We will accept tools that

- Solve a real, specific job-search problem.
- Have a working website and clear pricing.
- Have honest claims (no "guaranteed jobs," "guaranteed interviews," "100% match").
- Are not yet listed (or are listed but you have a substantive correction).

## We will not accept

- Spam tools
- Fake tools
- Broken links
- Link farms
- Tools with misleading claims (guaranteed jobs/interviews)
- Adult, gambling, weapon, or illegal tools
- Tools that mass-spam recruiters or hide what they submit
- Affiliate-link-only submissions with no real review

## Etiquette

- One PR per tool (don't bundle).
- Include the affiliation disclosure even if it feels obvious.
- Be patient — maintainer review can take a few days.
