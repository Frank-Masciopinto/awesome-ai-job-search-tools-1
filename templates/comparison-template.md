# Comparison Template

When comparing two tools (e.g. "TryApplyNow vs. Jobright"), use this template so the comparison stays honest.

```md
# [Tool A] vs. [Tool B]

Last updated: YYYY-MM-DD

## Summary

One paragraph. Who is each tool best for? Don't crown a winner — most readers have different needs.

## Side-by-side

| Feature | [Tool A] | [Tool B] |
|---|---|---|
| Free tier | Yes / Limited / No | Yes / Limited / No |
| Resume tailoring | Yes / No / Partial | Yes / No / Partial |
| Job matching | Yes / No / Partial | Yes / No / Partial |
| ATS scoring | Yes / No | Yes / No |
| Job tracker | Yes / No | Yes / No |
| Email finder | Yes / No | Yes / No |
| Auto-apply | Yes / No | Yes / No |
| Chrome extension | Yes / No | Yes / No |
| Mobile app | Yes / No | Yes / No |
| Pricing (entry paid plan) | $X / mo | $Y / mo |
| Cancellation | Easy / Hard | Easy / Hard |

## When to pick [Tool A]

- Concrete use case 1
- Concrete use case 2
- Concrete use case 3

## When to pick [Tool B]

- Concrete use case 1
- Concrete use case 2
- Concrete use case 3

## What neither does well

Be honest. List 2-3 gaps that apply to both.

## Sources

- [Tool A pricing page] (link, date checked)
- [Tool B pricing page] (link, date checked)
- Reviewer disclosure: I am / am not affiliated with either tool.
```

## Rules

- **No fake winners.** If you're affiliated with one tool, disclose it.
- **Date-stamp** the comparison — pricing and features change.
- **Link to sources** for every numeric claim (pricing, features).
- Avoid superlatives ("best in the world," "#1 tool"). Be specific.
- Update or remove the comparison when the underlying products change.
