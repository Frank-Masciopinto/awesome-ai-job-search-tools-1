# ATS Resume Tool Checklist

Use this before and after you run any ATS resume tool.

## Before running an ATS tool

- [ ] You have the full job description copied (not just the title).
- [ ] Your resume is a clean PDF, not a Word doc with weird formatting.
- [ ] You have a baseline version (so you can compare before / after).
- [ ] You know your "must-have" claims and won't fabricate to chase keywords.

## Format checks

- [ ] Single column layout.
- [ ] Standard font (Inter, Arial, Calibri, Georgia, Times).
- [ ] No tables for layout.
- [ ] No graphics that contain important text.
- [ ] No headers / footers with critical info.
- [ ] Section headers: Education, Experience, Projects, Skills.
- [ ] One page (student / new grad) or two pages (3+ YOE).

## Keyword checks (per JD)

- [ ] Role title or close equivalent appears in your resume.
- [ ] Top 5-7 required skills are present.
- [ ] Tools and frameworks named in the JD are present (only if you have them).
- [ ] Acronyms + full forms both included if relevant (e.g. NLP and Natural Language Processing).
- [ ] Location / work type matches.
- [ ] Required degree / graduation year is clear.

## Bullet quality checks

- [ ] Every bullet has an action verb.
- [ ] Every bullet names the tech or method used.
- [ ] At least 60% of bullets have a measurable result.
- [ ] No "helped," "assisted," "worked on," "responsible for."
- [ ] Strongest bullets are at the top of each role.

## After running the tool

- [ ] Read the missing-keyword list.
- [ ] Add only keywords you can defend in an interview.
- [ ] Rewrite weak bullets.
- [ ] Re-export PDF.
- [ ] Re-run the checker.
- [ ] Aim for 70%+ match, not 100%.

## Final sanity check

- [ ] Read your resume out loud.
- [ ] Open it on your phone — is it still legible?
- [ ] Send it to a friend in the field — would they recommend you for the role?
- [ ] Apply.
