# Safe Auto-Apply Checklist

Auto-apply tools can save time but they also cause real damage when misused — bad applications hurt your reputation at the company, and on some screening questions a wrong checkbox can disqualify you legally.

Use this checklist before, during, and after running any auto-apply tool.

## Before you turn it on

- [ ] You can see **what** the tool submits (resume, cover letter, screening answers).
- [ ] You can **review** each submission before send.
- [ ] You have a **strict filter** for role title, level, and location.
- [ ] You have at least one **tailored resume** the tool will use.
- [ ] You have a **maximum daily cap** set (suggested: 10-20).
- [ ] You know how to **stop** or pause it instantly.

## Filters to set

- Role title (close matches only)
- Seniority (intern / new grad / mid / senior)
- Location and work type
- Work authorization filter (so it doesn't auto-apply to no-sponsorship roles if you need sponsorship)
- Excluded companies (current employer, scam-flagged companies)
- Excluded keywords (e.g. "commission only," "MLM")

## Screening question rules

- [ ] **Never** let the tool auto-answer:
  - Work authorization / visa status
  - Salary expectations
  - Years of experience for required skills
  - Background check / drug test consent
  - Sponsorship needed
- [ ] If the tool can't ask you, **skip the application** instead of guessing.

## What to track per submission

- Company + role + apply timestamp
- Resume version used
- Cover letter version used
- Whether the application was reviewed by you
- Outcome (no reply / screen / reject)

## Weekly review

- [ ] What's your reply rate vs. tailored manual applications?
- [ ] Are you applying to roles you'd actually take?
- [ ] Any company flagging you as a spam applicant? (LinkedIn signals: "Your application was viewed" vs. silence over 50+ apps)
- [ ] Is the tool worth what you're paying for it?

## Hard "do not" list

- Don't run auto-apply at **dream companies**. Manual + referral wins.
- Don't run auto-apply on **senior roles**. Recruiters spot generic applications instantly.
- Don't auto-apply with **incorrect work authorization** info. That can disqualify you legally.
- Don't auto-apply if you can't measure outcomes.
- Don't let the tool **spam the same employer** 5x a week.

## A better default

For every 10 minutes you'd spend on auto-apply:

- 5 min: read the JD carefully.
- 3 min: tailor 1-2 bullets.
- 2 min: find one referral and send a short note.

That ratio beats 50 untargeted applications most weeks.
