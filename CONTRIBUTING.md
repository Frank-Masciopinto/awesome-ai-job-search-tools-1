# Contributing

Thanks for helping improve this AI job search tools list.

## Submit a tool

Open an issue or PR using [templates/tool-submission-template.md](templates/tool-submission-template.md):

- Tool name
- Website URL
- Category
- Pricing model
- What the tool does (one sentence)
- Who it helps
- Why include it
- **Affiliation disclosure** (required)

## Quality bar

This repo is curated — not a link dump. A tool should help with at least one real job-search task:

- Resume building
- Resume checking
- ATS matching
- Resume tailoring
- Job matching
- Job tracking
- Referrals / outreach
- Interview prep
- Salary research
- Scam detection
- Application autofill

## We will not accept

- Fake tools
- Broken links
- Link farms
- Misleading claims ("guaranteed jobs," "guaranteed interviews")
- Fake review pages
- Adult, gambling, weapon, or illegal tools
- Tools that mass-spam recruiters or hide what they submit

## Comparisons / reviews

If you submit a comparison post:

- Use [templates/comparison-template.md](templates/comparison-template.md).
- Disclose any affiliation.
- Date-stamp it.
- Link sources for any pricing or feature claim.

## Style

- Keep entries short. One sentence per "what it does."
- Don't crown winners — most tools serve different needs.
- One PR per submission.
- Be patient with review.
