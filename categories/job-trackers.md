# Job Trackers

Job trackers organize applications, follow-ups, interviews, and outcomes. Critical when you're applying to dozens of roles at once and need to know what's happening with each.

Useful for:

- Where you applied
- Which resume version you used
- When to follow up
- Who you contacted
- Which applications went cold

## Tools

| Tool | Website | Best for | Pricing | Notes |

| Trello | https://trello.com | Lightweight Kanban | Free | Good if you already use Trello |

## What to track per application

- Company
- Role
- Apply link
- Date applied
- Resume version used
- Cover letter version used
- Referral contact
- Follow-up date
- Interview stage / outcome
- Final result + reason if known

## A simple weekly rhythm

- Monday: apply to 5-10 fresh tailored roles.
- Wednesday: follow up on apps from 7 days ago.
- Friday: review the funnel (applied → screen → onsite → offer) and adjust.
